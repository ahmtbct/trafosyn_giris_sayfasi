# trafosyn_giris_sayfasi
TRAFOSYN modülleri için giriş sayfası (`index.html`).

- Logonun üzerine gelince logo hafifçe büyür ve açıklama pop-up'ı açılır.
- Logoya tıklayınca ilgili bağlantıya gidilir.
- Dokunmatik ekranda ilk dokunuşta açıklama gösterilir, ikinci dokunuşta bağlantı açılır.

## Bağlantıları / açıklamaları düzenleme

`index.html` içindeki `MODULES` listesinde her modülün `url` ve `description`
alanlarını doldurun. Bağlantıların yeni sekmede açılması için
`OPEN_IN_NEW_TAB = true` yapın.
